# 📊 CSV Data Dashboard — Portfolio Project

Python tool that reads **any CSV** and generates a beautiful self-contained HTML dashboard with charts and stats. No server needed — just open in a browser.

Built by **Oscar J. Villa García** · [ojviga@gmail.com](mailto:ojviga@gmail.com)

---

## 🚀 Quick Start

```bash
git clone https://github.com/oscarjvilla290/data-dashboard.git
cd data-dashboard && pip install -r requirements.txt
python src/dashboard.py data/your_file.csv
```

---

## ✨ Features

- Auto-detects numeric vs categorical columns
- Line charts for numeric distributions
- Bar charts for top categorical values
- Stats: min, max, mean, median, std dev, null count
- Dark-mode, single HTML file output

---

## 🛠️ Tech Stack

**Python 3.11+** · **pandas** · **Chart.js 4** (CDN)
